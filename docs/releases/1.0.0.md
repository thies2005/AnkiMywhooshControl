# ClickControl 1.0.0 — Controller presets for Android

First curated stable release of the Android app under the new 1.0.0 release series.

- Route supported Zwift Click controller buttons to Anki and MyWhoosh actions.
- Create and edit named presets for button presses and holds.
- Choose controller ownership in Settings and an AnkiDroid or laptop Anki destination in Android presets.
- Signed APK and AAB downloads include verified package metadata and SHA-256 checksums.

The displayed version restarts at 1.0.0; the Android version code increases. The current release signing key is preserved. Older debug-signed APKs require backing up app data and reinstalling before switching to this release key. Uncommitted local development changes are not included.

Download the APK to install. This release is Android-only; desktop build artifacts remain in GitHub Actions. Actual controller and target-app compatibility still needs device-specific testing. Some actions require explicitly enabled accessibility permissions.
